# NutriScan legacy landing page

The active NutriScan website is [getnutriscan.com](https://getnutriscan.com/), maintained in the private `getnutriscan/nutriscan-companion` repository and published through Lovable.

This public GitHub Pages repository keeps the older `getnutriscan.github.io/nutriscan-landing/` address working as a redirect for existing links. Its previous feature and pricing copy remains available in Git history.

Keep `app-ads.txt` until the seller IDs and any external references to this Pages URL are verified. Its Google publisher ID differs from the file in `nutriscan-companion`, so the files should not be treated as interchangeable.
